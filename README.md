# Task Plus — Phase 1

Mobile-first, chat-style task tool: send plain text or a voice note to a person or department; an LLM turns it into a structured task card for the recipient.

| Folder | What |
| --- | --- |
| `server/` | Node.js + TypeScript API (Fastify, SQL Server via Kysely) |
| `app/` | Flutter app (Android, iOS) |
| `infra/` | `docker-compose.yml`: SQL Server, Redis, API |
| `docs/` | `SETUP.md`, `DECISIONS.md` (architecture, API and review script come in later milestones) |

Start with [docs/SETUP.md](docs/SETUP.md).
